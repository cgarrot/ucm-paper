## Reading order for a newcomer

1. `docs/VISION.md` — why the project exists.
2. `docs/REPORT-V0.md` — the first capability.
3. `docs/REPORT-V1BIS-FINAL-v2.md` — the transfer campaign and its honest non-demonstration.
4. `docs/REPORT-S2B-FINAL.md` + `docs/ERRATUM-REPORT-S2B-2026-09-24.md` — recurrence kill and its scope.
5. `docs/REPORT-CYCLE-S2B-P2-FINAL.md` + the three errata that correct it — the honest cycle closing.
6. `docs/passation-*` (working repository only) — handover deltas; not mirrored here.

## Notes

- Language: French. The English paper (`paper/PAPER.md`) is the synthesis; this archive is the evidence trail.
- Some documents are append-only errata: never edit them, always add. The same convention applies here.
- Paths inside these documents refer to the working repository layout (`artifacts/`, `reports/`, `docs/`), which is not mirrored in full.
